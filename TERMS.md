# Boto Studio Terms

By using Boto Studio, you confirm that:

- You are responsible for the scripts you run and the files they access.
- Boto runs scripts on your computer under your current user account.
- Scripts can modify files, networks, and system state depending on what they do.
- You should only run scripts you understand and trust.
- Boto does not guarantee script safety or correctness.
- Scheduled tasks may run without a visible UI and should be reviewed before enabling them.

Boto Studio stores automation data locally on the computer and never uploads scripts or outputs to a remote service.

This project is for offline local automation only; it is not an AI agent, cloud service, or remote execution platform.
