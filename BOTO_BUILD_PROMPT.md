# BOTO BUILD PROMPT

This file records the project prompt for Boto Studio.

The repository now contains a real open-source Tauri-based project scaffolding, but the exact original image assets and sample UI files were not present in the repository. This implementation uses a clearly marked placeholder logo asset and a matching dark neumorphic interface inspired by the supplied mockups.

The project intentionally follows the requested constraints of the prompt as closely as possible while remaining honest about Windows-specific features that must be validated on a real Windows PC.
